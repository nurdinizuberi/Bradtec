# BRADTEC Logo — Place Your Logo Here

Place the official BRADTEC CO. LTD logo file in this folder with either name:

```
assets/images/logo.png
```

or

```
assets/images/bradt.png
```

Once the file exists, the website automatically uses it in:

- The sticky navigation bar (top-left)
- The footer

Until the file is added, the site shows a temporary text wordmark ("BRADTEC CO. LTD") so the layout stays intact. No code changes are needed — just drop the file in and re-upload.

> Tip: use a PNG with a transparent background, roughly 600×200 px or larger for crisp display on high-DPI screens.
